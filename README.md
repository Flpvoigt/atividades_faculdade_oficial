Sobre este repositório
Disponibilizei este repositório para que vocês possam consultar as atividades de Python que estou refazendo. 
Os códigos podem servir como base de estudo e ajudar na resolução de dúvidas.
Conforme eu for refazendo novas atividades, adicionarei os códigos a este repositório. 
Atualmente, ele contém exercícios sobre estruturas sequenciais, condicionais e de repetição, além de outros conceitos básicos de lógica de programação.
Estou resolvendo as atividades de maneira didática, evitando, sempre que possível, o uso de funções, listas, importações e métodos prontos. 
Por isso, alguns códigos podem estar mais longos do que o necessário. 
O objetivo é mostrar cada etapa do algoritmo e facilitar a compreensão da lógica.
Os textos iniciados por # dentro dos arquivos são comentários que utilizo para identificar as atividades e explicar algumas partes dos códigos.
Tentei usar nomes de variáveis que representassem o que elas armazenam. 
Porém, alguns exercícios ainda possuem nomes genéricos, como x, y, z, a e b. 
Como os algoritmos são simples, normalmente é possível entender a função de cada variável pela leitura do código. 
Se necessário, posso melhorar esses nomes.
Caso vocês tenham alguma dúvida sobre as atividades ou queiram entender melhor algum código, é só me chamar no WhatsApp.
